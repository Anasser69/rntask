# RN Task Project

A comprehensive React Native mobile application demonstrating modern development practices and integration of various libraries.

## Project Overview

This React Native application is built using the latest features and best practices, providing a robust foundation for mobile app development.

## Key Technologies & Libraries

### Core Technologies
- React Native
- TypeScript
- React Navigation 6.x

### State Management
- Redux Toolkit
- Redux Persist

### UI Components
- React Native Paper
- React Native Vector Icons
- React Native Reanimated

### Network & Data Handling
- Axios
- React Query

### Authentication
- @react-native-firebase/auth
- @react-native-google-signin/google-signin

### Storage
- @react-native-async-storage/async-storage
- @react-native-firebase/storage

### Forms & Validation
- React Hook Form
- Yup

### Development Tools
- ESLint
- Prettier
- Jest
- React Native Testing Library

## Features
- User Authentication (Email/Password & Google Sign-in)
- Real-time Data Synchronization
- Offline Data Persistence
- Responsive UI Components
- Form Handling & Validation
- File Upload & Management
- Push Notifications
- Deep Linking
